# Product Context

## Overview

HelpMe Agent เป็นผู้ช่วย AI แบบ Helpdesk (Microsoft Copilot Studio) สำหรับพนักงาน/ตัวแทนของ Deves Insurance ใช้ตอบคำถามและให้คำแนะนำเบื้องต้นเกี่ยวกับระบบงานภายใน (เช่น DSS, Renewal Motor, Polisy 400, PCS, CMI) โดยยึดคำตอบจากฐานความรู้ที่ได้รับการอนุมัติแล้วเท่านั้น เมื่อไม่สามารถตอบได้ ระบบจะรวบรวมรายละเอียดปัญหาและเปิดเคสส่งต่อเจ้าหน้าที่ พร้อมแจ้งทราบผู้แจ้งและติดตามสถานะเคส

## Problem Statement

พนักงาน/ตัวแทนต้องการคำตอบและการรับเรื่องที่รวดเร็ว แต่ทีม Helpdesk มีจำนวนจำกัดและคำถามซ้ำจำนวนมาก การตอบด้วยคนทำให้ช้าและไม่สม่ำเสมอ อีกทั้งเคสที่รับเข้ามายังขาดการแจ้งทราบผู้แจ้งและการติดตามสถานะที่ชัดเจน ทำให้ผู้แจ้งไม่ทราบความคืบหน้า จึงต้องมี AI agent ที่ตอบคำถามที่ตอบได้ทันที เปิดเคสอย่างเป็นระบบเมื่อตอบไม่ได้ และสื่อสารสถานะกลับผู้แจ้งผ่านอีเมล

## Target Users

- **ผู้แจ้งปัญหา (End User)**: พนักงาน/ตัวแทนที่ใช้ระบบงานภายในและต้องการความช่วยเหลือหรือแจ้งปัญหา
- **ทีมเจ้าหน้าที่ / Owner**: IT Helpdesk, ฝ่ายรับประกันภัยรถยนต์, IT/SA, ฝ่ายบัญชี, IT/Infrastructure ที่รับเคสไปดำเนินการต่อ
- **ผู้ดูแลฐานความรู้ / แอดมิน**: ผู้ที่ปรับปรุงและอนุมัติเนื้อหาใน AI_KnowledgeBase_Helpdesk และดูแลกฎการส่งต่อ

## Key Features

- **ตอบจากฐานความรู้ที่ยืนยันแล้ว**: ตอบเฉพาะ Approved_Answer พร้อมอ้าง KB_ID; ถามข้อมูลเพิ่มตาม Required_Information ก่อนสรุป
- **เปิดเคสเมื่อตอบไม่ได้**: รวบรวมรายละเอียดปัญหาให้ครบ แล้วบันทึกเคสลง SharePoint และส่งต่อเจ้าหน้าที่ตามกฎการส่งต่อ (Escalation_Rule / Owner)
- **แจ้งทราบผู้แจ้ง (Acknowledgment)**: ส่งอีเมลยืนยัน "รับเคสแล้ว" พร้อม CaseID ให้ผู้แจ้ง
- **ติดตามสถานะเคส (Follow-up)**: แจ้งความคืบหน้า/ปิดเคส และเตือนเคสค้างตามสถานะ/เวลา
- **การส่งต่อและแจ้งเตือนทีม**: ระบุผู้รับผิดชอบตามระบบ และส่งอีเมลแจ้งทีมที่เกี่ยวข้อง
- **ดูแลคุณภาพฐานความรู้**: guardrails ห้ามเดา, ห้ามใช้รายการที่ยังไม่ Active/ยัง Review Required, ห้ามเก็บ Password/OTP

## Project Type

- **Type**: Brownfield
- **Scope**: Enhancement — ต่อยอด agent เดิม โดยเพิ่มการแจ้งทราบผู้แจ้งและการติดตามสถานะเคส และปรับปรุง flow การเปิดเคส/ส่งอีเมล
